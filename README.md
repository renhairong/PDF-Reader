# 云轩 PDF 阅读器

> 网页版 PDF 阅读器 · 双页看书 · 零服务器上传 · 纯本地运行

一个基于 pdf.js 的纯前端 PDF 阅读器，支持单页连续滚动和对开页双排阅读。**所有文件在浏览器本地处理，不会上传到任何服务器。**

## 功能

### 📖 阅读体验
- **单页连续滚动**（默认）↔ **双排对开页** 一键切换
- 缩放：放大 / 缩小 / 适应宽度 / 百分比显示
- 页码跳转，双排模式下显示「第 X-Y / N 页」
- 窄屏（≤768px）自动降级为单页
- 全屏阅读模式

### 🔍 工具
- 搜索高亮（pdf.js findController）
- TOC 目录侧栏（自动解析 PDF 大纲）
- 上次读到哪（localStorage 记忆）
- 打印（直接调用系统打印预览）

### 💬 文字批注
- **选中文字** → 弹出浮动菜单（📋 复制 / 💬 批注）
- 批注内容保存后自动**黄色高亮选中区域**，首字符外侧显示气泡图标
- 鼠标悬停气泡查看批注内容，点击气泡可**编辑或删除**批注
- **多选行选中**逐行自动高亮
- IndexedDB 持久化：重新打开 PDF 批注自动恢复
- 工具栏 ⚙️ 设置菜单可开关「显示 PDF 内嵌批注」

### 🌙 个性化
- 暗色 / 亮色模式切换
- 最近打开 5 条记录（IndexedDB 持久化，可单条删除 / 全部清空）
- 主页按钮快速返回空态
- 自定义确认弹框

## 快速开始

### 方式一：开机自启（推荐）

```bash
git clone https://github.com/renhairong/PDF-Reader.git
cd PDF-Reader
npm install
./install-service.sh
```

运行后访问 http://localhost:8137 即可使用。**以后每次开机自动在后台启动**，无需任何操作。

### 方式二：手动启动

双击项目中的 `start.command` 文件，自动打开浏览器。关闭终端窗口后服务停止。

### 更新

```bash
cd PDF-Reader
git pull
```

然后刷新浏览器即可，无需重启服务。

### 卸载开机自启

```bash
./install-service.sh --remove
```

## 使用说明

1. 拖入 PDF 文件到页面，或点击「打开文件」选择
2. 顶部工具栏可切换单/双页、缩放、搜索、目录、暗色模式等
3. 最近打开的文件会显示在主页空态下方，点击直接加载
4. 点击主页按钮（⌂）回到空态，切换其他文件

## 技术栈

- [pdf.js](https://mozilla.github.io/pdf.js/) — PDF 渲染引擎
- 原生 JavaScript，单 HTML 文件
- IndexedDB + localStorage — 本地持久化
- Python http.server — 开发服务器
