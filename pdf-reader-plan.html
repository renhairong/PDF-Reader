网页版 PDF 阅读器 · 实现方案

目标：保留默认单页连续滚动，新增「对开页连续滚动」（双排看书）。纯前端，原生 JS + pdf.js。本文含架构、双排核心逻辑、交互细节与版本迭代计划。

1. 产品目标与 MVP 范围

核心形态：默认单页连续滚动；一键切换「对开页连续滚动」——左右两页并排、一起向上滚（spreadMode=EVEN，第 1 页起即双排，无单独封面行）。

技术底座：原生 JS + pdf.js，单 HTML 可跑，文件本地上传/拖拽、不上传服务器；窄屏自动退化为单页。

第一版 MVP 功能：

MVP本地上传/拖拽打开 · MVP单页滚动 ↔ 双排滚动切换 · MVP缩放(适应宽度+放大/缩小+百分比) · MVP页码/进度(双排显示第 X-Y/N 页)+跳页 · MVP工具栏 UI · MVP加载态/错误提示 · MVP重新打开/换文件

迭代阅读进度记忆 · 迭代TOC 目录 · 迭代搜索 · 迭代文本复制 · 迭代打印/下载 · 迭代旋转/暗色

2. 技术架构

不重写布局引擎，直接复用 pdf.js 自带的 PDFViewer 组件（已内置 scrollMode / spreadMode / 缩放 / 可见性渲染）。我们只在它之上做工具栏和模式切换 UI，工作量最小、最稳定。

3. 目录结构（单页部署）

pdf-reader/ ├── index.html // 单页入口，内嵌工具栏 + 容器 ├── app.js // 初始化 PDFViewer、模式切换、缩放、页码逻辑 ├── style.css // 工具栏 / 双排 gutter / 窄屏降级样式 └── lib/ └── pdfjs/ // pdf.js 本地副本（发布时离线可用） ├── pdf.mjs ├── pdf.worker.mjs └── pdf_viewer.mjs // 含 PDFViewer 组件
开发期可先用 CDN（unpkg.com / cdn.jsdelivr.net）引入 pdf.js 快速验证；发布时把 lib/pdfjs 打进本地目录，实现纯离线、文件不出本机。

4. 核心：双排布局逻辑

pdf.js 把「滚动方向」与「页面排布」做成两个正交维度，组合即可拼出目标效果：

scrollModespreadMode = NONEspreadMode = EVEN（双排）
VERTICAL（垂直）单页连续滚动（默认保留）对开页连续滚动（本次目标）
切换只需两行赋值：
viewer.scrollMode = pdfjsLib.ScrollMode.VERTICAL;
viewer.spreadMode = isTwoPage ? pdfjsLib.SpreadMode.EVEN : pdfjsLib.SpreadMode.NONE;

4.2 关键技术点

要点实现方式
双排开/关按钮 + 快捷键（如 V）在 VERTICAL+NONE 与 VERTICAL+EVEN 间切换，状态记忆到变量
缩放与布局viewer.currentScaleValue 支持 'page-width'（适应宽度）、'1'、'1.5' 等；放大/缩小按钮按步进调整，双排时两页同步缩放
页码 / 进度监听滚动，取视口内/中心页；双排显示「第 X-Y / N 页」，跳页调用 viewer.scrollPageIntoView
窄屏降级matchMedia('(max-width:768px)') 或 resize：窄屏强制 spreadMode=NONE，宽屏恢复用户选择
横版页(landscape)渲染时判断 viewport.width > viewport.height，给该页容器加 class 使其跨满整行（CSS 跨列），不强行塞进双排
加载态 / 错误解析期间显示 loading；getDocument 失败 catch 后提示文件损坏/不支持
大文件性能依赖 PDFViewer 原生可见性渲染（只渲染视口内页）；超大型后续加虚拟列表
风险点：pdf.js 的 EVEN 双排是「统一两列」网格，横版页跨列需要给单页容器加 CSS 跨列 class（监听 pagerendered 事件后处理）。这是方案里唯一需要少量自研布局 hack 的地方，工作量可控。

5. 工具栏与交互

控件行为
打开文件按钮触发 <input type=file> + 整窗拖拽放置，读取为 ArrayBuffer 传给 pdf.js
单页 / 双排分段开关，点击或 V 键切换；图标区分
缩放「− / 百分比 / +」与「适应宽度」按钮
页码显示「第 X-Y / N 页」，点击可输入跳页
重新打开再次选/拖入新 PDF，复用同一 viewer 实例

7. 验收标准

✓ 打开任意 PDF，默认单页连续滚动正常，无错位

✓ 切双排后第 1 页起即双页并排、一起向上滚；缩放后两页布局正确、可读

✓ 窄屏（<768px）自动退化为单页；回到宽屏恢复双排

✓ 页码正确显示（双排「第 X-Y / N 页」），跳页精准

✓ 200+ 页大文件滚动流畅，无长时间白屏（有 loading 提示）

✓ 损坏文件有清晰错误提示，不崩溃
